kept because they record decisions and defect histories that still explain why
the code looks the way it does — not because any of them describes the current
system.

**Nothing in here is the current architecture.** For that, read
[`../../README.md`](../../README.md) and
[`RUNTIME_ARCHITECTURE.md`](../RUNTIME_ARCHITECTURE.md).
